# Bodega — Sistema de Inventario

App de inventario para bodega/mercado: control de stock, rotación y precios por punto de venta. HTML/CSS/JS puro, un solo archivo (`index.html`), sin backend — los datos viven en `localStorage` del navegador.

## Uso

Abrir `index.html` directamente en el navegador, o servirlo como sitio estático (GitHub Pages, etc.).

## Datos

Los productos y su historial de precios se guardan localmente en el navegador. Para respaldo/migración, exportar desde la app.
